# Autoreply — رد آلي في واتساب بالكلمة أو الرقم

العميل يكتب كلمة أو رقماً (مثل `1` أو `المنيو`) فيرد البوت فوراً بصوت أو صورة أو فيديو أو ملف ثم النص.
مشروع متعدد العملاء: نشر واحد يخدم عدة أنشطة، وكل نشاط له رقمه ورمزه وقواعده.

## الملفات
- `supabase/schema.sql` — الجداول: businesses, rules, message_log + الحماية (RLS) + حاوية الملفات `rule-media`.
- `src/app/api/webhooks/whatsapp/route.ts` — نقطة استقبال Meta الوحيدة لكل العملاء.
- `src/lib/reply.ts` — يجد النشاط من `phone_number_id`، يطابق القاعدة، يرسل الملفات ثم النص.
- `src/lib/matcher.ts` — مطابقة الكلمات (مأخوذة من الديارة) + الأرقام كاختيارات قائمة.
- `src/lib/whatsapp.ts` — الإرسال والرفع والتحقق من التوقيع، برمز كل نشاط.
- `src/lib/crypto.ts` — تشفير رمز واتساب لكل نشاط قبل حفظه.

## الفحوصات
```bash
npm install
npm run typecheck
npm run check
```

## ما لم يُبنَ بعد
لوحة تحكم العميل (تسجيل الدخول، إضافة القواعد، رفع الملفات) وصفحة ربط رقم واتساب.
